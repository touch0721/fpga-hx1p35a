## `SC520GainTbl` 增益编码穷举校验（逻辑推演）

`step` 取值 0..127，`coarse = step[6:5]`、`fine = 0x20 + step[4:0]`：

| 条件 | step | 输出 `{0x3e08, 0x3e09}` | 增益 | 落在表 2-4 |
| --- | --- | --- | --- | --- |
| `I_AG <= 16` | 0 | `{03, 20}` | 1.000x | ✓ |
| `17 <= I_AG <= 31` | 1..15 | `{03, 21..2f}` | 1.031x..1.469x | ✓ |
| `I_AG = 32` | 16 | `{03, 30}` | 1.500x | ✓ |
| ... | ... | ... | ... | ✓ |
| `I_AG = 48` | 32 | `{07, 20}` | 2.000x | ✓ |
| `I_AG = 80` | 64 | `{0f, 20}` | 4.000x | ✓ |
| `I_AG = 112` | 96 | `{1f, 20}` | 8.000x | ✓ |
| `I_AG = 143` | 127 | `{1f, 3f}` | 15.750x | ✓ |
| `I_AG >= 144` | 127（钳位） | `{1f, 3f}` | 15.750x | ✓ |

- `step` 0..127 **恰好 128 个值**，与表 2-4 的 128 行一一对应，无遗漏、无越界。
- `fine = 0x20 + step[4:0]` 恒落在 0x20~0x3f，**符合表 2-3 对 `0x3e09` 合法区间的规定**。
- `I_AG` 旧上限 176 已无法达到，为避免 `I_AG>=144` 段出现编码空洞，已钳位到表 2-4 顶端
  （15.750x，即规格标注 16x 的最后一档；手册表 2-4 中不存在 16.000x 条目）。
